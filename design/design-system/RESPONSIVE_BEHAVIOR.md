# Responsive Behavior

> **Document role:** Normative UX/visual specification.

## Mobile

Primary reading order:
- system state
- main action
- transaction context
- supporting detail
- technical explanation

Technical diagrams may scroll horizontally rather than being reduced beyond legibility.

## Tablet

Use two-column layouts where both columns remain readable.

## Desktop

Use a 12-column composition with generous outer margins.

## Wide displays

Do not stretch body text indefinitely. Keep technical and editorial content within readable measure.

## Touch

Controls should remain easy to activate without relying on hover.

## Navigation

Mobile uses a full-height structured menu rather than a tiny condensed desktop navigation.
