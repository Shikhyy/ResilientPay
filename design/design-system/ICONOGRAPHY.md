# Iconography

> **Document role:** Normative UX/visual specification.

## Philosophy

Icons should behave like technical symbols.

The set should be custom-drawn and derived from the system vocabulary.

## Required icon families

### Transport
- NFC
- BLE
- QR
- internet
- SMS

### Transaction
- authorize
- sign
- transfer
- store
- synchronize
- reconcile

### Security
- credential
- signature
- counter
- verification
- rejection

### Device
- payer
- merchant
- phone
- terminal

## Style

- one visual stroke family
- geometric construction
- minimal internal detail
- works at 16, 20, 24, and 32px
- monochrome by default
- semantic accent only when required

No generic icon library should be used as the brand icon system.
