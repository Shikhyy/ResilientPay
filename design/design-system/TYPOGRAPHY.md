# Typography

> **Document role:** Normative UX/visual specification.

## Primary type

IBM Plex Sans for interface and product communication.

## Technical type

IBM Plex Mono for:
- transaction references
- state identifiers
- counters
- protocol identifiers
- API paths
- data labels

## Editorial type

Source Serif 4 for selected research passages and long-form narrative.

## Rules

Do not use Inter, Geist, or Space Grotesk.

Headings should be compact, precise, and sentence case.

Avoid all-caps paragraphs. All-caps is reserved for short labels, metadata, and navigation markers.

Numbers should have strong typographic alignment in research tables.

## Example

```text
PROTOCOL / MOPP-0.1

A transaction can remain locally
authorized without being presented
as finally reconciled.
```

The visual system should make technical status values easy to scan.
