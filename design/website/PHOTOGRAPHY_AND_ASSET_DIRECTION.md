# Photography and Asset Direction

> **Document role:** Normative UX/visual specification.

## Goal

Photography should prove physicality.

Preferred subjects:
- Android devices used in field testing
- NFC tags
- QR markers
- merchant counters
- charging and connectivity conditions
- network hardware
- engineers testing the prototype

## Composition

Use close crops, directional light, real environments, and visible material texture.

Avoid staged smiles and generic technology stock photographs.

## Illustration

Use diagrammatic line work derived from actual system architecture.

Preferred:
- signal paths
- transaction envelopes
- device silhouettes
- state timelines
- transport diagrams

Avoid:
- abstract floating 3D blobs
- glowing futuristic circuitry
- decorative network webs with no meaning
